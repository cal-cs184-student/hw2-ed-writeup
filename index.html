The main lesson was keeping geometry separate from connectivity. Moving a vertex changes the shape, while rewiring halfedges changes which elements are neighbors. Subdivision does both, so every new position is computed before any edge is split. Automated checks after every edit (twin symmetry, closed face loops, edge ownership, complete vertex rings) caught pointer mistakes long before they showed up on screen.

Section I: Bezier Curves and Surfaces

Part 1: Bezier curves with 1D de Casteljau subdivision

de Casteljau's algorithm evaluates a Bezier curve by repeated linear interpolation. Each step replaces every adjacent pair of points with \( p_i' = (1 - t)p_i + t\,p_{i+1} \), so n points become n − 1. After n − 1 steps, one point remains, and it lies on the curve. evaluateStep performs one step and returns a new vector.

The custom curve curve6.bzc has control points (0.12, 0.20), (0.25, 0.85), (0.42, 0.12), (0.60, 0.90), (0.78, 0.30), and (0.92, 0.70). The images use t = 0.5. The full curve is green, the control polygon white, the intermediate levels blue, and the evaluated point red.

Part 2: Bezier surfaces with separable 1D de Casteljau

A Bezier surface applies de Casteljau in two directions. evaluate calls evaluate1D on each row of control points at u, giving one point per row. It then calls evaluate1D once more on those points at v. evaluate1D repeats the 3D evaluateStep, which uses the same interpolation as Part 1, until one point remains.

Section II: Triangle Meshes and Half-Edge Data Structure

Part 3: Area-weighted vertex normals

Vertex::normal walks the faces around the vertex with h = h->twin()->next() and skips virtual boundary faces. For each triangle it adds \( (p_1 - p) \times (p_2 - p) \). That vector points along the face normal, and its length is twice the face area, so the sum is already area-weighted. The sum is normalized at the end. A zero sum is returned as-is to avoid NaNs.

Part 4: Edge flip

For an interior edge a–b shared by triangles (a,b,c) and (b,a,d), the flip reuses the same edge as c–d, producing faces (c,d,b) and (d,c,a). The six halfedges of the two triangles are rewired, and the affected faces and vertices get updated halfedge pointers. Nothing is created or deleted, so a flip takes constant time. Boundary edges are returned unchanged.

The main pitfall is stale vertex pointers. After a flip, a and b can point at a halfedge that no longer leaves them, so their pointers must be reassigned. For debugging, automated checks run after every edit. They confirm that twins are symmetric, face loops close, edges own their halfedges, and every vertex ring is complete. The tests, including 100 interleaved splits and flips, also pass under AddressSanitizer and UndefinedBehaviorSanitizer.

Part 5: Edge split

The split adds a vertex m at the edge midpoint. The two original halfedges keep their source vertices and get new twins starting at m. On each side, a new edge from m to the opposite vertex cuts the triangle in two. The two halves of the original edge are marked old and the new cross edges are marked new; Loop subdivision uses these flags later.

An interior split adds 1 vertex, 3 edges, 6 halfedges, and 2 faces. A boundary split adds 1 vertex, 2 edges, 4 halfedges, and 1 face, because only the real side is cut. Both take constant time.

Extra credit: boundary edge splits. Only the interior triangle is split; the virtual boundary face just gains one edge. Testing this on an open square exposed a bug in the provided loader. It created boundary faces without a halfedge pointer, which broke traversal of the boundary loop. Assigning each one its first boundary halfedge fixed it.

Part 6: Loop subdivision for mesh upsampling

upsample runs in three steps:

  1. Compute new positions for every old vertex and every edge midpoint, using the original mesh.
  2. Split each original edge, iterating over a saved list so new edges are never split. Then flip every new edge that joins an old vertex to a new one.
  3. Copy the stored positions into the mesh.

Computing every position first means each weight uses original positions, so the result doesn't depend on processing order. The position rules are:

  • Old interior vertex of degree n: \( (1 - nu)\,p + u \sum p_i \), with \( u = 3/16 \) if n = 3, otherwise \( 3/(8n) \).
  • New vertex on interior edge (A, B) with opposite vertices C, D: \( \tfrac{3}{8}(A + B) + \tfrac{1}{8}(C + D) \).
  • Boundary (extra credit): old vertex \( \tfrac{3}{4}p + \tfrac{1}{8}(a + b) \) using its two boundary neighbors; new vertex \( \tfrac{1}{2}(A + B) \).

Every new position is a weighted average of its neighbors, so sharp corners and edges get rounded off and the cube shrinks. It also becomes lopsided. In dae/cube.dae, the diagonals that split the faces aren't arranged symmetrically, so the eight corners have degrees 3, 4, 4, 4, 5, 5, 5, and 6. Loop weights depend on degree, so corners that should be equivalent move by different amounts, and the difference grows each round.

The fix is to split each face's diagonal once, which turns every face into a symmetric fan of four triangles around its center. Every corner then has degree 6 and every face center has degree 4. All corners move identically, so the cube stays symmetric. It still rounds off, because symmetry doesn't preserve sharpness.

Pre-splitting edges near a corner keeps it sharper. The extra vertices close to the corner limit how far the averaging pulls it inward. This reduces rounding but can't create a permanent crease. (Optional) Section III: Potential Extra Credit - Art Competition: Model something Creative

The mesh is a closed ring with five lobes, three vertical waves, and varying tube thickness. tests/generate_model.py generates it with 40 samples around the ring and 10 around the tube, giving 400 vertices and 800 triangles. One and two Loop rounds produce 3,200 and 12,800 triangles.

Instead of the tutorial humanoid, the shape is a torus modified by a center radius \( R(u) = 1.8 + 0.28\cos 5u \), a tube radius \( r(u) = 0.34(1 + 0.18\sin 3u) \), and a height \( z(u) = 0.24\sin 3u \). Subdivision smooths the coarse tube facets but keeps the large waves.
